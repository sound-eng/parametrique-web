2-channel 8-band parametric EQ Per-channel EQ with a live response graph, presets, and process attenuation.
Two processing modes Virtual device keeps EQ after you quit; System audio EQs whatever is already playing (no driver required).
Volume that fits your device Menu-bar volume via the virtual device, or Level / Balance mirrored to hardware when available.

Quick install

  1. Download and open Parametrique-<version>.pkg.
  2. Complete the installer (one admin password prompt).
  3. Launch Parametrique from /Applications.
  4. Open Parametrique → Settings → Mode and pick one:
    • Virtual device — set Parametrique EQ Device as output in System Settings → Sound, then choose your speakers under Proxied device.
    • System audio — leave your normal output selected, grant Audio Recording if prompted, and keep Parametrique running.
