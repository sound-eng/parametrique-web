Install Parametrique

Step-by-step guide for macOS.

Before you start

Parametrique requires macOS 14.6 or later. The installer places the Parametrique app and the optional HAL audio driver on your Mac.

Choose a processing mode in Parametrique → Settings → Mode. Only one is active at a time.

  • Virtual device — install the driver (included in the package), set Parametrique EQ Device as system output. EQ keeps running after you quit the app.
  • System audio — no driver required for playback. Parametrique taps the current default output, applies EQ in the app, and plays it back. EQ stops when you quit. Needs System Settings → Privacy & Security → Audio Recording permission.

1. Download

Get the latest .pkg from the download page or GitHub Releases.

2. Run the installer

  1. Double-click Parametrique-<version>.pkg.
  2. Follow the installer prompts and enter your admin password when asked.
  3. When finished, the app (and driver) are installed system-wide.

3. Launch Parametrique

  1. Launch Parametrique from /Applications.
  2. Open Parametrique → Settings and choose Mode: Virtual device or System audio.

4a. Virtual device mode

  1. Open System Settings → Sound.
  2. Under Output, choose Parametrique EQ Device.
  3. In Parametrique → Settings, under Proxied device, choose the physical output you want to hear — speakers, headphones, or interface.
  4. Without a proxied device, audio routed through Parametrique goes to the first device in the list.
  5. If output is silent, raise the Parametrique EQ Device level in Audio MIDI Setup.

4b. System audio mode

  1. Leave your normal speakers or interface selected as the default output in System Settings → Sound (not Parametrique EQ Device).
  2. In Settings → Mode, choose System audio. Grant Audio Recording if macOS prompts you.
  3. Keep Parametrique running (or enable Minimize to menu bar on close so EQ continues after you close the window).
  4. Change the default output anytime — Parametrique follows. Quitting the app returns audio to normal immediately.

5. Configure EQ

  1. Adjust the 8-band EQ, Level, Balance, and process attenuation in the main window.
  2. Change buffer size or other options in Settings if needed.
  3. In Virtual device mode, EQ remains active after you quit — reopen only to change settings. In System audio mode, EQ runs only while the app is open.

Uninstall

Open Parametrique → Settings → Driver → Uninstall… and follow the embedded uninstaller (removes the HAL driver). Afterwards, remove the app from /Applications.

System audio mode does not need the driver; you can leave the driver uninstalled if you only use that mode.

Troubleshooting

  • No sound (Virtual device) — confirm Proxied device is set in Parametrique → Settings, and raise Parametrique EQ Device level in Audio MIDI Setup.
  • No sound / permission (System audio) — allow Parametrique under System Settings → Privacy & Security → Audio Recording. Do not set Parametrique EQ Device as the default output in this mode.
  • Crackling or pops — increase buffer size in Parametrique → Settings (available in both modes).
  • Driver not found — reinstall from the latest .pkg release, or switch to System audio mode.
  • Diagnostics — Parametrique → Settings → Diagnostics (Copy / Export…).
